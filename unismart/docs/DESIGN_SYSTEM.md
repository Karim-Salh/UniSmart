# نظام التصميم – UniSmart v2

**الهوية**: كحلي عميق (Navy) + أزرق حديث + لمسة Indigo، خلفيات فاتحة هادئة، وتدرّج واحد فقط (الترحيب وشعار النظام).
**الأنماط (Tokens)** في أول ملف `assets/style.css`: `--bg --card --ink --mut --line --ac --ac2 --soft --navy --grad --sh`، ونمط داكن عبر `[data-theme=dark]` (يدوي أو تلقائي من النظام).
**الخط**: IBM Plex Sans Arabic + Inter للأرقام اللاتينية.

## المكوّنات
Shell (شريط جانبي قابل للطي + شريط علوي: بحث، مظهر، إشعارات، صورة المستخدم) · Card · Stat/Mini · Badge · Button (أساسي/ثانوي/نصي) · Input/Select/Switch/Segmented · Table · Ring/Progress · Popover (الإشعارات، الملف الشخصي) · Modal (تعديل الملف، اقتصاص الصورة، التحقق بالوجه) · Empty state · Skeleton · Error box · Calendar/Schedule · Face verification panel.

## السلوك
- الملف الشخصي مدمج في لوحة التحكم + قائمة منبثقة + نافذة تعديل (لا صفحة مستقلة).
- الصورة الشخصية: يضيفها الطالب مرة واحدة (مع اقتصاص ومعاينة) ثم تُقفل؛ التغيير من الإدارة فقط، وللطالب «طلب تغيير» يصل للإدارة كإشعار.
- جوال: الشريط الجانبي درج منزلق، والشبكات تعيد الترتيب (لا تصغير فقط).
- إتاحة: روابط تخطٍّ، حلقات تركيز، `aria-*`، إغلاق بـ Esc، تباين مناسب، احترام `prefers-reduced-motion`.

## هيكل الواجهة
`frontend/*.html` صفحات رفيعة تشترك في `assets/app.js` (منطق وعرض) و`assets/style.css`. الحالة في `sessionStorage` والتفضيلات (المظهر، الحضور، الإشعارات) في `localStorage`.
